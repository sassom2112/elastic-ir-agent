Architecture

Step 1 — Triage Agent
Gemini 2.5 Flash investigates
Calls 6 ES|QL detection tools via Elastic Agent Builder MCP — blast radius, credential access, process injection, lateral movement, attack timeline. Produces a structured IR report.
Step 2 — Elastic Memory
ELSER + BM25 hybrid search
Agent writes enriched findings back to Elasticsearch. Hybrid sparse-vector + keyword retrieval surfaces prior-session context on demand. Session-scoped at the ES filter level.
Step 3 — Forensic Auditor
Independent adversarial pass
Second Gemini instance — read-only tools, no access to triage history. Re-queries Elastic, labels every MITRE claim VERIFIED / REFUTED / UNVERIFIABLE with the specific ES|QL output.
Step 4 — Audit Trail
Chain-of-custody JSONL
Every tool call atomically appended via os.open/os.write — not buffered IO. Rejected calls log the reason. Allowed calls log duration and arguments.

Security Model — Architecturally Enforced

Bad actions are architecturally impossible — not instructed away. Prompt injection, cross-session data leakage, and write-to-wrong-index are blocked in code, not by telling the model to be careful.
Session isolation
search_memory filtered by session_id at the Elasticsearch query level. The model cannot reach another investigation's data — it's not instructed away from it.
Input validation
time_window: regex match + 100-year DoS cap. host_name: alphanumeric allowlist + ES|QL char blocklist. All integers range-checked before any ES call.
Write allowlist
write_memory checks the target index against a hardcoded frozenset at write time. Misconfiguring ELASTIC_INDEX_MEMORY=ir-events is caught in the tool, not at startup.
Content sanitisation
write_memory strips control characters and caps input at 10,000 chars — blocking indirect prompt injection via poisoned retrieval results.
Split API keys
ELASTIC_API_KEY_READ for ES|QL queries. ELASTIC_API_KEY_WRITE for the memory index only. The read path cannot write under any circumstance.
Chain-of-custody log
Every tool call atomically appended via os.open/os.write (not buffered IO). Rejected calls log the rejection reason; allowed calls log duration and all arguments.
